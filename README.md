# Hero Travel

A responsive travel agency landing page built with HTML, CSS, and vanilla JavaScript.

## Tech Stack

- HTML5
- CSS3 (Custom Properties, Flexbox, Grid)
- Bootstrap 5.3
- Bootstrap Icons
- Google Fonts (Poppins)
- Vanilla JavaScript

## Sections

- **Navbar** — Sticky with scroll shadow effect and active link highlight
- **Hero** — Full background image with search bar (destination, month, type)
- **Popular Tours** — Auto-sliding image carousel with feature list
- **Destinations** — Masonry-style destination cards grid
- **Why Choose Us** — Three feature cards with icons
- **Deals & Discounts** — Full-bleed image cards with floating overlay
- **Testimonials** — Six review cards with animated stat counters
- **Video** — Preview image with modal video player
- **Newsletter** — Region-based carousel text with subscribe form
- **Footer** — Social links and copyright

## JavaScript Features

1. Sticky navbar shadow on scroll
2. Active nav link updates based on scroll position
3. Mobile navbar auto-close on link click
4. Newsletter region dropdown with carousel text rotation
5. Subscribe form validation with success state
6. Testimonial stat counters animate on scroll into view

## Getting Started

No build tools or dependencies required. Just open `index.html` in a browser.
```bash
# Clone the repo
git clone https://github.com/your-username/hero-travel.git

# Open in browser
open index.html
```
